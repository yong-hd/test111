# 추적 손절 + 반등 확인 재매수 규칙 v2 — KODEX 200

상태: 확정(백테스트 전)   결정: 2026-10-03 대표

## 0. 공통
- 판단은 t일 **확정 종가**, 체결은 t+1일 **시가**. 장중 가격으로 판단하지 않는다.
- 가격은 원주가, 분배금은 `backtest/price-dividend-contract.md`를 따른다.
- 한도는 `guardrails/limits.md`를 따른다: 보유 상한 10주, 1회 주문 최대 2주, 1일 기안 1회.
  (예외는 3절의 손절 매도뿐이며, 채택 시 대표가 limits.md에 직접 추가한다.)

## 1. 처음 진입 — 나눠서
- 시작 후 매 거래일 2주씩 매수해 10주까지 채운다(5거래일).
- 진입 중에도 2·3절이 적용된다(첫 매수일 종가부터 고점 추적).

## 2. 보유 중 — 익절 없음
- 오르는 동안에는 팔지 않는다.
- 기준 고점 = 매수 이후 가장 높은 종가(오를 때만 갱신).

## 3. 분할 손절 — 확정
- **1차**: 종가가 고점 대비 −S%에 닿으면, 다음 날 시가에 절반을 판다(홀수면 올림). 이때의 종가를 C1로 기록한다.
- **2차**: 그 뒤 어느 날이든 종가가 C1보다 5% 더 낮으면, 다음 날 시가에 나머지를 판다.
- **되돌림**: 절반만 남은 상태에서 종가가 고점을 다시 넘으면, 나머지 절반을 다시 산다.
- 세부: '고점'은 1차 직전 기준 고점이며 50% 상태에서는 갱신하지 않는다. 2차 판정은 1차 체결일 종가부터. 되돌림 후 C1을 지우고 되돌림일 종가부터 고점을 다시 추적한다.
- 손절 매도는 1회 2주 한도의 예외로 보유분의 50%까지 한 번에 판다(백테스트 비교 버전 (1)).
- 되돌림 매수는 1회 2주 한도를 따른다.

## 4. 전량 매도 후 재매수 — 나눠서
- 기준 저점 = 전량 매도 이후 가장 낮은 종가(내릴 때만 갱신).
- **1단계 [A]**: 종가가 기준 저점 대비 +10% 이상 → 5주까지 매수(하루 2주씩).
- **2단계 [B]**: 종가가 20일 이동평균 위 → 10주까지 매수(하루 2주씩).
- A·B가 같은 날 충족되면 10주까지 이어서 매수한다(하루 2주씩).
- 재매수 첫 체결일 종가부터 고점을 새로 추적하고, 2·3절이 다시 적용된다.

## 5. 고르는 값과 고정값
- 고르는 값: S ∈ {8, 10, 12, 15} — **보정 구간(2014-07-08~2020-12-30)에서만** 고른다.
- 고정값: 1차 비중 50%, 2차 추가 하락 5%, 재매수 A +10%, B 20일. 후보로 돌리지 않는다(과최적화 방지).

## 6. 검증 방식
- 평가 구간(2021-01-04~2026-10-01)은 S를 고른 뒤 한 번만 평가한다.
- 비교 대상: 일괄매수, 현행 규칙(익절 8%·추가매수 −3%·상한 10주), v2.
- v2 손절 버전 비교(같은 S·같은 재매수): (1) 분할 손절 + 손절 예외, (2) 신호 시 전량 손절(예외), (3) 손절도 하루 2주(예외 없음).
- 지표: 세전 총수익률, 최대 낙폭, 매매 횟수, 현금 대기 비율, 최장 현금 대기 기간, 상한 도달 기간.
- 백테스트는 한도(하루 1회·1회 2주·상한 10주)를 그대로 반영한다.
