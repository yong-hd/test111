# 추적 손절 + 반등 확인 재매수 규칙 (v2 초안) — KODEX 200

상태: 초안 (백테스트 전)   결정: 2026-__-__ 대표 ______

## 공통
- 판단은 t일 **확정 종가**, 체결은 t+1일 **시가**. 장중 가격으로 판단하지 않는다.
- 가격은 원주가, 분배금은 `backtest/price-dividend-contract.md`를 따른다.
- 상태는 둘 중 하나다: **보유 중** / **현금 대기 중**.

## 1. 처음 진입
- 시작일 다음 거래일 시가에 [ 전액 / 한도 내 최대 ] 매수.

## 2. 보유 중 — 추적 손절
- 기준 고점 = 매수 이후 가장 높은 종가 (매수일 종가부터 시작, 오를 때만 갱신).
- 종가가 기준 고점 대비 **-S%** 이하이면 다음 거래일 시가에 전량 매도.
- 오르는 동안에는 팔지 않는다(익절 없음).
- S 후보: 8 / 10 / 12 / 15 — **보정 구간(2014-07-08~2020-12-30)에서만** 고른다.

## 3. 현금 대기 중 — 반등 확인 후 재매수 (하나 선택, 또는 둘 다 시험)
- 기준 저점 = 매도 이후 가장 낮은 종가 (내릴 때만 갱신).
- [A] 저점 반등: 종가가 기준 저점 대비 **+R%** 이상이면 다음 거래일 시가에 재매수. R 후보: 5 / 10
- [B] 추세 회복: 종가가 **N일 이동평균** 위로 올라오면 다음 거래일 시가에 재매수. N 후보: 20 / 60
- 재매수하면 기준 고점을 재매수일 종가로 새로 시작한다.

## 3-1. 분할 손절 (대표 제안안, 2026-10-03)
- 보유 비중은 100% / 50% / 0% 세 단계.
- 1차 손절: 종가 ≤ 기준 고점 × (1 - S%) → 다음 거래일 시가에 보유분의 **절반(홀수면 올림)** 매도. 이때의 판단 종가를 C1로 기록.
- 2차 손절: 이후 어느 날이든 종가 ≤ C1 × 0.95 (C1 대비 추가 -5%) → 다음 거래일 시가에 나머지 매도.
  - [ 선택 ] '1차 다음 날 하루만' 보는 방식은 하루 -5%가 드물어 나머지 50%가 거의 팔리지 않으므로 권장하지 않음.
- 50% 상태에서 종가가 기준 고점을 다시 넘으면 → 다음 거래일 시가에 나머지 절반 재매수, 기준 고점 갱신.
- 0% 상태의 재매수는 3절 조건을 따른다([A] 충족 시 절반, [B] 충족 시 나머지 — 또는 한 번에 전량, 대표 선택).
- 비율(50/50)과 추가 하락폭(5%)은 고정하고 후보로 돌리지 않는다(과최적화 방지).
- 한도와의 관계(limits.md 12~13행): '1회 최대 2주'·'1일 기안 1회'는 매수·매도 구분이 없다.
  손절 매도에만 예외를 둔다 — 아래 문구를 대표가 limits.md에 직접 추가하는 것을 전제로 한다.
  > 손절 매도(rules-v2 3-1절)는 1회 주문 한도 2주의 예외로, 1회에 보유분의 50%(홀수면 올림)까지 매도할 수 있다. 1일 기안 1회는 그대로 적용한다.

## 4. 잦은 매매 방지 (선택)
- 매도 후 최소 [ 0 / 5 ]거래일은 재매수하지 않는다.
- 확인 조건이 [ 1 / 2 ]거래일 연속 충족될 때만 재매수한다.

## 5. 수량 한도
- `guardrails/limits.md`의 보유 상한 10주·1회 최대 2주를 [ 그대로 적용 / 별도 결정 후 변경 ].
- 그대로면 진입·재매수도 하루 2주씩 나눠 들어간다.
- 손절 매도는 3-1절의 예외(1회 최대 보유분 50%)를 따른다. 그 외 매수·매도는 1회 2주 그대로.
- 백테스트는 이 한도를 그대로 반영해야 실제 운용과 같아진다(하루 1회·최대 2주).

## 6. 검증 방식
- 후보 조합은 보정 구간에서만 비교해 하나를 고른다. 평가 구간(2021-01-04~2026-10-01)은 고른 뒤 한 번만 평가한다.
- 비교 대상: 일괄매수, 현행 규칙(익절 8%·추가매수 -3%·상한 10주), v2.
- 지표: 세전 총수익률, 최대 낙폭, 매매 횟수, 현금 대기 비율, 최장 현금 대기 기간.
- 비교 버전: (1) 분할 손절 + 손절 예외, (2) 한 번에 전량 손절, (3) 손절도 1회 2주 한도 그대로 — 같은 S·같은 재매수 조건.
