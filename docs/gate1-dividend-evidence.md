# 해제 조건 1 — 배당 반영 계약 근거 기록 (2026-10-02)

투자위원회 "보류 + 추가 검증"의 해제 조건 1번(배당 반영 계약)을 정하기 위해 확인한 사실.
조회는 모두 읽기 전용(Sam: kiwoomcli 조회, Ada: 코드·공식 출처 조회). 파일 생성·주문·Supabase 쓰기 없음.

## 1. 정정: 현재 백테스트는 "분배금 제외"가 아니다

- 수집·백테스트는 키움 `ka10081 --adjusted true` 가격만 쓴다 (`scripts/backfill_prices.py`, `backtest/backtest.py:39-52`).
- Sam 대조(2026-04-29, 07-30 전후): 수정/원주가 차이가 분배락일마다 분배금만큼 줄어든다 → **키움 수정주가는 분배금을 비율 보정으로 반영**.
- 따라서 보고서의 `dividends_included=false`와 "분배금 제외 가격수익률" 해석은 틀렸다(Ada 정정 확인).
  수정주가 위에 분배금을 현금흐름으로 더하면 **이중계상**.

## 2. 키움 수정주가의 600봉 경계 결함

2014-07-01~2026-10-02 공통 3,008거래일, |비율 변화| ≥ 0.0001 경계 46개 = 분배형 41 + 비분배 5.

| 날짜 | 비율 변화 | 수정주가에 생기는 가짜 등락 |
|---|---|---|
| 2014-07-11 | 1.000000 → 0.969606 | 약 -3.0% |
| 2016-12-16 | 1.000000 → 0.944912 | 약 -5.5% |
| 2019-06-04 | 1.000000 → 0.954617 | 약 -4.5% |
| 2021-11-08 | 1.000000 → 0.955296 | 약 -4.5% |
| 2024-04-15 | 1.000000 → 0.952012 | 약 -4.8% |

- 원주가는 이 날짜 전후로 연속이다. 분배·분할 공시와도 무관.
- 경계 간격이 정확히 600거래일(첫 구간 8봉, 마지막 구간 조회일 포함 600봉) → **키움 수정주가는 600봉 조회 페이지마다 수정계수를 따로 잡는다(확정)**. 조회 기준일이 바뀌면 경계도 이동한다.
- 백테스트 스냅샷(2014-07-08~2026-09-29, 3,000봉) 안의 경계 4개 — 600·1,200·1,800·2,400번째 행:

| 날짜 | 수정주가 등락 | 원주가 등락 | 가짜 등락 |
|---|---|---|---|
| 2016-12-13 | -5.33% | +0.19% | -5.52%p |
| 2019-05-30 | -3.66% | +0.92% | -4.58%p |
| 2021-11-03 | -5.82% | -1.42% | -4.41%p |
| 2024-04-09 | -5.39% | -0.62% | -4.77%p |

  → 기존 백테스트·일괄매수·낙폭(-40.81%) 수치는 이 가짜 하락을 포함한다. 수정주가는 해제 판정 근거로 쓰지 않는다.
